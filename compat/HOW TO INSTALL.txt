LEGO Star Wars: The Complete Saga Portable - installing on your PS Vita
==================================================

You need a homebrew-enabled Vita (HENkaku/Enso) with VitaShell.

ONE-TIME SETUP (skip anything you already have)
  1. kubridge v0.3.1 or newer: put kubridge.skprx in ur0:tai and add this line
     under *KERNEL in ur0:tai/config.txt:
         ur0:tai/kubridge.skprx
  2. fd_fix: put fd_fix.skprx in ur0:tai and add under *KERNEL:
         ur0:tai/fd_fix.skprx
     (Skip fd_fix if you use the rePatch plugin.)
  3. libshacccg.suprx in ur0:data - use ShaRKBR33D to get it in one step.
  4. Reboot the Vita.

INSTALLING THE GAME
  1. Connect the Vita to your PC with VitaShell (USB or FTP).
  2. Copy what's inside the "ux0" folder from "Ready For Vita" onto the Vita,
     so everything ends up in  data/lswtcs/  on ux0:, uma0: or grw0:
     (use uma0:/grw0: if your SD2Vita is mounted there - the game checks
     ux0: first, then uma0:, then grw0:).
  3. Download LSTCS-P.vpk from the GitHub release page, copy it anywhere on
     ux0:, select it in VitaShell and press X to install.
  4. Launch "LEGO Star Wars: The Complete Saga Portable" from the home screen.

If the game says files are missing, check that data/lswtcs/ (on one of those drives) contains
libTTapp.so, Audio.dat, Levels.dat, Others.dat and Textures.dat.

REPORTING A PROBLEM
  The game keeps a  debug  folder inside data/lswtcs/ with everything needed to
  look into a problem:
    lstcs-log.txt            what happened this session
    lstcs-log-previous.txt   the session before (so a crash's log isn't lost)
    screenshots/             pictures taken at start-up, after each level loads,
                             once a minute, and whenever you press L + R + SELECT
    screenshots-previous/    the session before's pictures
  If the game crashed, also grab the newest .psp2dmp file from ux0:data/.
